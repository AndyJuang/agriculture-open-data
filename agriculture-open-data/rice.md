# 糧情調查 EIR837

來源為農糧署，更新頻率每年。依《農業部農業資料開放平臺 API 介接說明書，糧情調查》v1.0（2025-07-31）。

- API 為 `https://data.moa.gov.tw/Service/OpenData/FromM/TownRiceData.aspx`。
- 篩選條件為 `year`（民國年）、`name`（期作，例如一期作）、`city`、`town`、`cropCode`、`crop`，均可省略。說明書的臺東縣範例使用「台東縣」。實際可取得的期作、年份與地名以回傳為準。
- 作物代碼為 C01 稉稻、C02 硬秈稻、C03 軟秈稻、C04 稉糯稻、C05 秈糯稻、C06 陸稻。範例回傳代碼帶尾端空白，核對時先去空白。
- 面積欄位以公頃計，稻穀及糙米總產量以公斤計，原始單位產量欄位沿用官方值。單筆的欄位順序可變。
- 文件列出 JSON、XML、CSV，腳本讀取 JSON。JSON 查無資料時回傳空陣列。文件示例數字為格式示範。
- `$top`、`$skip` 用於分頁，單次上限 1,000 筆。腳本持續查到空頁，即使中途回傳少於請求上限也會繼續，並檢查頁面完全重複的狀況。
