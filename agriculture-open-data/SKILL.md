# 農業開放資料查詢

從需求判斷指標、作物、地區、期間、時間粒度與交付格式。使用者未指定輸出時，少量資料給表格，需要明細時輸出 CSV。只有來源口徑或範圍存在會實質改變答案的歧義時才追問。

## 糧情調查 EIR837

讀取 [糧情調查規格](rice.md)。用 `scripts/fetch_rice.py --help` 查看參數。年度參數可重複，縣市、鄉鎮、期作和作物使用 API 接受的名稱或代碼。例如：

```sh
python3 scripts/fetch_rice.py --year 2020 --year 2021 --city 花蓮縣 --period 一期作 --crop-code C01 --output rice.csv
```

實際執行時用技能資料夾內的腳本路徑，並把輸出放進使用者可存取的資料夾。若一個地名或作物有數種官方寫法，可先查較廣範圍以確認原始欄位值，再重跑或在本地精確篩選。需要多個地區或多個作物時分批抓取，合併時保留原始欄位並核對重複與涵蓋範圍。

逐年回報取得筆數與空回傳。只有以官方行政區清單或使用者提供的預期範圍核對後，才指出個別鄉鎮未出現在結果中。彙總種植、收穫面積及產量前先確認明細粒度，避免把彙總列與明細重算。需計算整體單位產量時，確認口徑後用合計產量除以合計收穫面積，分母為零時留空。

## 其他資料集

1. 搜尋[官方資料目錄](https://data.moa.gov.tw/open.aspx)或[資料集清單](https://data.moa.gov.tw/open_detail.aspx?id=172)，開啟候選資料集官方詳細頁與介接文件。比較提供機關、指標定義、資料粒度、涵蓋期間及更新頻率。注意產地、批發與零售價格的口徑差異。
2. 優先使用該資料集官方 API 或下載檔。依該規格確認欄位、日期格式、單次上限與完整取數方式。查詢期間不在現行介接的涵蓋範圍時，找官方歷史檔。跨資料集合併前核對時間粒度、地理層級、單位和品項代碼。
3. 有網路工具但腳本執行環境無法連網時，嘗試用可用工具存取同一官方來源。若僅能讀到部分資料、無法確認分頁完整性，或整批擷取失敗，回報實際取得範圍和原因。也可接受使用者提供的官方下載檔繼續整理。

交付時附上官方來源、查詢條件、擷取日期、單位、實際涵蓋範圍，以及空回傳或未取得的範圍。使用 API 真實回傳或官方下載資料進行分析。
